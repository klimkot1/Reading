# Подключение естественной озвучки

Статус: подготовлено, но живой API-вызов без ключа и аккаунта провайдера не выполнялся. В интерфейсе ни один нейроголос не показан активным до создания и прослушивания записей.

## Схема

Голоса генерируются серверным инструментом заранее, а не во время детской диагностики. Ключ не попадает в браузер. В облако отправляется только фиксированный набор английских названий букв и слов, без имени ребёнка, ответов и записей его речи.

Три оригинальных профиля — Орби, Луна, Искра — используют разные базовые голоса и инструкции выразительности. Они не имитируют известных персонажей или людей. Изменение голоса применяется к названиям букв и словам во всей диагностике. Эталонные фонемы остаются отдельными проверенными записями.

## Подготовка аккаунта

Нужны аккаунт OpenAI API с доступом к Realtime, ключ с подходящими правами и установленный предел расходов. Подписка ChatGPT сама по себе не подтверждает этот доступ. Для безопасного получения ключа в Codex используйте плагин OpenAI Developers и его `openai-platform-api-key`, когда он доступен. Не присылайте ключ в чат.

1. В этой папке установить зависимости командой `npm install`.
2. Скопировать `.env.example` в локальный `.env`, заполнить ключ и проверить доступность указанной модели в аккаунте. `.env` исключён из Git.
3. Сначала создать только одну пробу: `node --env-file=.env generate.mjs --profile orbi --token letter:a`.
4. Прослушать `../dist/assets/neural/orbi/letter-a.wav`. Если результат подходит, запустить `node --env-file=.env generate.mjs --profile orbi --all`. Этот запуск делает платные запросы; оцените стоимость и лимит до запуска.
5. Прослушать все 42 записи. Проверить правильное английское название каждой буквы, отсутствие слова `letter` и любых добавочных фраз, естественность и отчётливость произношения. Утверждённые записи отметить `approved: true` в `review-orbi.json`; затем отметить общий `approved: true`.
6. Активировать: `node activate.mjs --profile orbi`. Скрипт проверяет полноту, одобрение и контрольные суммы. Только после этого профиль получает `ready: true` в `voice-bank.json` и `voice-bank.js`.
7. Повторить для `luna` и `spark`, затем опубликовать проект. Активные варианты появятся в «Настройки → Озвучка».

Одна запись названия проигрывается клиентом три раза с паузами. Генератор не просит модель произносить дополнительные инструкции. Автоматическая проверка транскрипта отсеивает явные лишние слова, но не заменяет прослушивание фонетики.

## Документация и ограничение проверки

Интеграция подготовлена по [Realtime conversations](https://developers.openai.com/api/docs/guides/realtime-conversations) и [Getting started with Realtime](https://developers.openai.com/api/docs/guides/realtime). Используется поток PCM 24 kHz из `response.output_audio.delta`, преобразуемый в WAV. Старый Speech API не выбран как основа: в [Text to speech](https://developers.openai.com/api/docs/guides/text-to-speech) указан его предстоящий вывод из эксплуатации.

Схемы запросов и обработчики покрыты локальными проверками. Реальная совместимость аккаунта, доступность модели, тембр и качество произношения проверяются после подключения провайдера. Обновления API проверять по официальной документации перед запуском.
