# Орбита — диагностика чтения

Детская платформа для проверки английских букв, звуков и коротких CVC-слов. Интерфейс — на русском, проверяемый материал — на английском.

## Запуск

Статический сайт не требует сборки или API-ключа. Из корня проекта:

```sh
python -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Можно также открыть `dist/index.html` напрямую; HTTP-сервер предпочтительнее.

## Проверки

Нужен Node.js 22 или новее. Корневые проверки не требуют установки зависимостей и не обращаются к платному API:

```sh
npm test
```

500 сценариев алфавита и CVC: порядок A–Z, варианты, первые ошибки, пять порогов наград, результаты CVC. Голосовой протокол проверяется с имитацией транспорта.

## Что работает

- 26 названий A–Z и 26 звуков, независимые результаты.
- Пять звуковых форматов, ответ во время озвучки, фиксация всех попыток.
- Медали за 5, 10, 15, 20 и 26 букв подряд без ошибок в названии и звуке.
- 12 CVC-заданий: чтение → картинка, сборка услышанного слова, выбор написанного слова.
- Автоматический переход к CVC после предварительного порога по буквам; запуск CVC отдельно.
- Отчёты родителю, JSON, печать, локальное сохранение и продолжение.

## Ограничения текущей версии

Данные хранятся в localStorage браузера. Серверная база данных, регистрация, семейные аккаунты и синхронизация ещё не реализованы. Автоматическая оценка детского произношения, чтения связного текста и понимания не подключена. Результат выбора ответа не является результатом оценки речи или стандартизированной клинической диагностики.

Озвучка названий и слов пока браузерная. Три нейроголоса подготовлены к подключению, но не активированы. Настройка и генерация записей описаны в [voice-service/README.md](voice-service/README.md). Не помещайте API-ключ в браузер, Git или чат. Подготовка записей использует платный API только при отдельном запуске с ключом.

## Структура

```text
dist/                 Статический сайт, игровые модели и ресурсы
voice-service/        Серверный инструмент подготовки и проверки озвучки
tests/                Проверки диагностики и голосового протокола
DIAGNOSTIC-SPEC.md     Действующий сценарий и правила подсчёта
ART-DIRECTION.md       Происхождение иллюстраций и звуковых реакций
```

Главные модели — `assessment-core.js`, `game-core.js`, `diagnosis-core.js`, `cvc-core.js`; действующий интерактивный сценарий — `experience.js`. В проекте сохранены ранние интерфейсные модули платформы; переход к серверной архитектуре требует отдельного этапа, а не включения существующей базы.

Служебная конфигурация Sites и его Git-история в эту копию не включены. Доступ к рабочему сайту не меняется при загрузке репозитория.

## Ресурсы и права

Фонемы встроены в приложение по лицензии Phonicademy. Атрибуция есть в настройках; лицензия и описание набора находятся в `dist/assets/phonemes/`. Не используйте эти файлы как отдельный аудиопак или для обучения/тестирования ML-моделей. Иллюстрации созданы с ImageGen; звуковые реакции синтезированы для проекта. Общая лицензия на исходники пока не выбрана владельцем; загрузка на GitHub не делает проект автоматически открытым ПО.
